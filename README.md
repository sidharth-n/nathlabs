# Natha Labs website

Marketing and compliance website for Natha Labs, a Dubai software studio providing custom application development, SaaS engineering, automation and technology consulting.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

The site is deployed on Vercel at [nathalabs.com](https://nathalabs.com).
